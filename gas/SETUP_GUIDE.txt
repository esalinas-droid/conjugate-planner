CONJUGATE PLANNER — GOOGLE SHEETS SETUP
=======================================

Do this once. It takes about five minutes and lets your training data live in
Google Sheets instead of on your phone.

Database Sheet:
https://docs.google.com/spreadsheets/d/1RMrZrcdkxUJUeDbWc-IZ8HMJlhzBEKuBAJXtJ7ngfWc/edit


STEP 1 — PASTE THE SCRIPT
-------------------------
1. Open the Sheet above.
2. Extensions > Apps Script.
3. Select everything in the editor and delete it.
4. Paste the entire contents of gas/Code.gs.
5. Near the top, change this line:
      const ACCESS_TOKEN = 'CHANGE_ME';
   to a private phrase only you know, for example:
      const ACCESS_TOKEN = 'squat650';
   Write that phrase down — you enter it in the app later.
6. Click the save icon.


STEP 2 — CREATE THE SHEET TABS
------------------------------
1. In the Apps Script toolbar, choose the function "setupSheets".
2. Click Run.
3. Google asks for permission the first time. Choose your account >
   Advanced > Go to (project name) > Allow. This is Google asking whether
   your own script may edit your own Sheet.
4. When it finishes, the Sheet has these tabs:
      Sessions           one row per workout, with set counts and tonnage
      Exercise_Log       one row per exercise, including logged sets
      PRs                best result per exact ME variation
      Custom_Exercises   exercises you create in the app
      Athletes_Settings  reserved for future use
      Sessions_Raw       hidden; the complete record the app reads back


STEP 3 — PUBLISH IT
-------------------
1. Deploy > New deployment.
2. Click the gear icon > Web app.
3. Description: anything, e.g. "Conjugate Planner".
4. Execute as: Me
5. Who has access: Anyone with the link
6. Deploy, then copy the Web app URL. It ends in /exec.

"Anyone with the link" means anyone holding that long random URL can reach the
script — that is why the access token matters. Do not post the URL publicly.


STEP 4 — CONNECT THE APP
------------------------
1. Open the planner and go to Settings.
2. Apps Script Web App URL: paste the /exec URL.
3. Access Token: type the same phrase from Step 1.
4. Tap "Test Google Sheets Connection". You should see a success message.
   If it fails, re-check the URL and token, and confirm Step 3 used
   "Anyone with the link".
5. Choose where sessions are stored:

      This device only
        Nothing leaves the phone.

      This device + Google Sheets
        Saved both places. Safest — survives a Sheets outage or a lost phone.

      Google Sheets only (minimal phone storage)
        Sessions live in the Sheet. The phone keeps just the session you are
        currently editing plus your settings.

6. If you switch to a Google Sheets option and already have sessions saved on
   the phone, the app uploads them automatically and tells you the count.


TRAINING WITHOUT SIGNAL
-----------------------
Cloud-only mode still works in a gym with no reception. Saving while offline
keeps the session on the phone and shows a warning. It uploads by itself as
soon as you reconnect, and Settings shows how many sessions are waiting. Do
not clear app data while sessions are still waiting.


UPDATING THE SCRIPT LATER
-------------------------
Saving in the Apps Script editor does NOT update the live web app. After any
edit you must run:
   Deploy > Manage deployments > pencil icon > Version: New version > Deploy
The URL stays the same, so nothing changes in the app.


TROUBLESHOOTING
---------------
"Invalid access token"
   The phrase in Settings does not match ACCESS_TOKEN in Code.gs.

"Missing sheet ... Run setupSheets()"
   Step 2 was skipped, or a tab was renamed or deleted.

Test Connection fails, or history stays empty
   The deployment is not published to "Anyone with the link", or you pasted
   the editor URL rather than the /exec deployment URL.

Nothing appears in the Sheet
   Check the storage setting in the app is not "This device only".


NOTES
-----
- Keep exporting a backup from Settings now and then. It is a single file and
  restores everything, including sessions still waiting to upload.
- Do not put Google account passwords or API keys into the app.
- The planner organises training. It is not a medical or diagnostic tool.
